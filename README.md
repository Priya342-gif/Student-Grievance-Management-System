# 🎓 Student Grievance Management System

A full-stack web application designed to help students **submit, track, search, and manage grievances** through a simple and secure platform.

## 🚀 Features

- 🔐 User Registration & Login
- 🛡️ JWT Authentication
- 📝 Submit Grievances
- 📋 View & Manage Grievances
- 🔎 Search Grievances
- 🔄 Update Grievance Status
- 📱 Responsive User Interface
- ⚡ RESTful APIs
- 🗄️ MongoDB Database

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- React Router
- Axios
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt.js

## 💻 Development

### Prerequisites

- Node.js
- npm
- MongoDB / MongoDB Atlas
- Git

### Clone Repository

```bash
git clone <YOUR_GITHUB_REPO_URL>
cd Student-Grievance-Management-System


Backend Setup
cd backend
npm install

Create a .env file:

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret

Run the backend:

npm run dev
Frontend Setup

Open a new terminal:

cd frontend
npm install
npm run dev
